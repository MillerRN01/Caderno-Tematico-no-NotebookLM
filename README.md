# Estudo sobre realidade virtual  para  jogos digitais
  Esse estudo visa entender como funciona a tecnologia de realidade virtual aplicada para jogos digitais, suas estruturas,  tecnologias aceitaveis, possiveis melhorias. Com tudo isso, procurase da a melhor experiencia para o jogador na sua imersao, sempre prejudicar o copor e a mente.
